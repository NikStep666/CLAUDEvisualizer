
# CLAUDEvisualizer

An MCP (Model Context Protocol) server that renders HTML/visualizations in a browser window with a cyberpunk engineering aesthetic.

## Overview

CLAUDEvisualizer is a specialized server designed to work with Claude and other AI models to visualize data and render web content directly in a browser. The project combines advanced visualization capabilities with an immersive cyberpunk-themed user interface.

## Features

- 🎨 **Cyberpunk Engineering Theme** - Dark, futuristic UI with neon accents and technical aesthetics
- 📊 **Board Mode with Edges** - Visualize relationships and connections between elements
- 💾 **Persistence** - Save and restore your visualizations and state
- 🌐 **HTML Rendering** - Display custom HTML and web-based content
- 🔌 **MCP Server** - Seamless integration with AI models and assistants

## Installation

```bash
git clone https://github.com/NikStep666/CLAUDEvisualizer.git
cd CLAUDEvisualizer
```

## Usage

1. Start the MCP server
2. Connect your AI model or application
3. Send visualization requests with HTML content
4. View rendered output in the browser window

## Configuration

The server can be configured to:
- Customize the cyberpunk theme colors and styling
- Set board display preferences
- Configure persistence storage location

## Architecture

- **MCP Server**: Handles protocol communication and request routing
- **Browser Window**: Renders HTML and visualizations
- **Board Engine**: Manages nodes, edges, and layout
- **Persistence Layer**: Stores visualization state and history
